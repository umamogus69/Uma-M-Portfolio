# Portfolio Template

A simple, personal portfolio website template — no build tools, no
frameworks, just HTML/CSS/JS. Fork it, make it yours, and deploy it for
free with GitHub Pages.

Made for the WCS portfolio workshop, but usable by anyone.

> Tip: once you deploy your own version, replace this line with a
> screenshot of your site — `![Preview](images/preview.png)`.

## Quick start

1. Click **Use this template** (green button, top of this repo page) →
   **Create a new repository**.
2. Clone your new repo:
   ```
   git clone https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
   ```
3. Open the folder in your code editor (e.g. VS Code), then open
   `index.html` in your browser to preview it.
4. Follow [`CUSTOMIZE.md`](CUSTOMIZE.md) to make it yours.
5. Deploy it — see below.

## Deploying with GitHub Pages (free)

1. Push your changes to GitHub.
2. Go to your repo's **Settings → Pages**.
3. Under "Build and deployment", set **Source** to `Deploy from a
   branch`, branch `main`, folder `/ (root)`.
4. Save. Your site will be live in a minute or two at
   `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`.

## What's in here

```
portfolio-template/
├── index.html         # your content lives here
├── css/
│   ├── theme.css       # colors & fonts — edit this first
│   └── style.css        # layout — you usually won't need to touch this
├── js/
│   └── main.js           # mobile nav toggle
└── images/
    └── profile-placeholder.svg
```
